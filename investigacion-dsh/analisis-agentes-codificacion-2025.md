# Análisis comparativo de agentes de codificación (2025) — contexto para DeepSeek Harness (dsh)

> Investigación web realizada vía `web_fetch` sobre fuentes primarias (repos GitHub, LICENSE, páginas de precios oficiales, npm registry, archive.org). Fecha de consulta: 2026-09-23 (los datos reflejan el estado más reciente publicado; los hitos de 2025 se citan explícitamente).

## Notas y fuentes por agente

### 1. Claude Code (Anthropic)
- **Licencia NO MIT**: el repo `anthropics/claude-code` es un repo de distribución/issues con código minificado; su `LICENSE.md` dice literalmente *"© Anthropic PBC. All rights reserved. Use is subject to Anthropic's Commercial Terms of Service."* → propietario. Fuentes: [repo](https://github.com/anthropics/claude-code), [LICENSE.md](https://raw.githubusercontent.com/anthropics/claude-code/main/LICENSE.md).
- Instalación: script nativo, Homebrew, WinGet; **npm deprecado**. npm: `@anthropic-ai/claude-code`. Fuente: [README](https://raw.githubusercontent.com/anthropics/claude-code/main/README.md).
- Docs oficiales (code.claude.com/docs): confirman secciones **Agent SDK** (`/docs/en/agent-sdk/overview`), **MCP** (quickstart+reference), **Skills**, **Plugins** (crear, marketplaces, evals), **Hooks** (`/docs/en/hooks-guide`), subagentes, agent teams, worktrees, headless, deployment en **Amazon Bedrock / Google Vertex AI / Microsoft Foundry / gateways**. Fuente: [docs overview (archivo)](https://web.archive.org/web/20260102060539/https://code.claude.com/docs/en/overview), [plugins (archivo)](https://web.archive.org/web/20260920185608/https://code.claude.com/docs/en/plugins), [costs (archivo)](https://web.archive.org/web/20260923192018/https://code.claude.com/docs/en/costs).

## Lectura rápida para el posicionamiento de dsh
- **Licencia**: dsh (MIT) es más permisivo que Claude Code/Cursor/Amp (propietarios) y Crush (FSL); equiparable a OpenHands (MIT) y más simple que los Apache-2.0 (Codex, Gemini CLI, Aider).
- **Agnosticismo**: dsh nace desacoplado del modelo (todo por plugins), al nivel de Crush/Aider/OpenHands; por encima de Claude Code, Gemini CLI (solo su familia) y Codex (parcial).
- **Extensibilidad**: el modelo "everything is a plugin" de dsh es más radical que los de la competencia (plugins + MCP + hooks + skills); solo OpenHands se acerca con ACP.
- **Madurez**: dsh está en developer preview; Claude Code, Cursor, Codex y Gemini CLI están GA y son los más maduros.
